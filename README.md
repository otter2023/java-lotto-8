## 🎯 미션 개요
사용자로부터 구입 금액을 입력받아 해당 금액만큼 로또를 발행하고, 당첨 번호 및 보너스 번호를 입력받아 당첨 내역과 수익률을 계산하는 **로또 발매기**를 구현한다.

<br>

## 📝 기능 요구 사항

### 1. 로또 구입
- 사용자는 구입 금액을 입력한다.
- 로또 1장의 가격은 1,000원이다.
- 구입 금액이 1,000원으로 나누어 떨어지지 않으면 예외를 발생시킨다.
- 구입 금액에 해당하는 수량만큼 로또가 발행된다.
- 제공된 Lotto 클래스를 사용한다.

### 2. 로또 번호 생성
- 로또 한 장은 1~45 사이의 중복되지 않는 6개의 숫자로 구성된다.
- 랜덤 번호 생성 시 `camp.nextstep.edu.missionutils.Randoms.pickUniqueNumbersInRange(1, 45, 6)`을 활용한다.
- 각 로또 번호는 오름차순으로 정렬하여 출력한다.

### 3. 당첨 번호 입력
- 사용자는 쉼표(`,`)로 구분된 6개의 당첨 번호를 입력한다.
- 이후 보너스 번호 1개를 추가로 입력한다.

### 4. 당첨 결과 판별
- 사용자 로또 번호와 당첨 번호를 비교하여 당첨 등수를 판별한다.
- 당첨 기준 및 상금은 다음과 같다:

| 순위 | 조건 | 상금 |
|------|------|------|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

### 5. 수익률 계산
- 당첨 금액의 총합을 구입 금액으로 나누어 수익률(%)을 계산한다.
- 수익률은 소수점 둘째 자리에서 반올림하여 출력한다.

### 6. 예외 처리
- 잘못된 입력 시 `IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력한다. 이때 `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.
- 에러 메세지 출력 후 해당 입력 단계부터 다시 입력을 받는다.
- `System.exit()` 호출은 금지한다.

1,2,3,4,5,6

7

## 🛠️ 프로그래밍 요구 사항

### 실행 환경
- JDK 버전: 21  
- 프로그램 시작점: `Application.main()`  
- 빌드 도구: Gradle

### 제약 사항
- `build.gradle` 파일 변경 금지  
- 외부 라이브러리 추가 금지  
- `System.exit()` 사용 금지  
- Random 값 추출 및 사용자 입력 값은 `camp.nextstep.edu.missionutils` 라이브러리 사용
- 제공된 Lotto 클래스를 반드시 사용
- Lotto에 numbers 이외의 필드(인스턴스 변수) 추가 금지
- numbers의 접근 제어자 변경 금지
- Lotto의 패키지를 제외한 파일, 패키지의 이름 변경 및 이동 금지

### 코드 컨벤션
- 기본적으로 [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) 준수  
- 추가로 [우아한테크코스 Java 코딩 컨벤션](https://github.com/woowacourse/woowacourse-docs/tree/main/styleguide/java) 준수 
- `indent depth` ≤ 2  
- `else` 및 `switch/case` 사용 금지  
- 삼항 연산자 금지  
- 메서드 길이는 15라인 이하
- 단위 테스트 작성  
- 메서드는 한 가지 일만 수행
- `Java Enum` 사용
